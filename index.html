Eco-Shop Smart Item Tracking

Build 001A • Store-based access • Multi-device

Initial Configuration

Enter your Supabase project URL and publishable/anon key. Never enter a service-role or secret key. These settings remain on this device.

Store Login

Start Staff Work Session

One store account can be used on multiple devices. Enter the actual operator's Staff ID on each device.

Scan & Record

Existing records are replaced with the latest physically counted quantity, not added. An audit event is retained.

Store Records

Location Recheck Session

Lock a location on the Scan tab first. Start a recheck, scan every item found in that location, then review unobserved records. Unobserved does not automatically mean CLEAR.

Camera Scanner

Requires HTTPS and a browser supporting BarcodeDetector. Otherwise use manual input or a Bluetooth scanner.
